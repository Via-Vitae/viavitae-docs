# Audito įrodymų saugykla

Šioje direktorijoje saugomi ISO 27001/SOC 2 pasiruošimo įrodymai: prieigos peržiūros
žurnalai, pratybų ataskaitos.

## Kas gali būti įkelta

- Anonimizuoti prieigos peržiūros žurnalai
- DR pratybų ataskaitos be asmeninių duomenų
- Pentestų santraukos be eksploatavimo detalių

## Kas negali būti įkelta

- Asmens duomenys bet kokia forma
- Gyvi prisijungimo duomenys ar raktai
- Klientų vardai ar tapatybės
